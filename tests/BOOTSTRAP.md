# 接入试运行用例

以下是待执行的验收场景，不代表已经通过。每次运行记录环境、日期、仓库提交、操作、预期结果、实际结果和证据链接。Work 与 Codex 分别验证。

1. **正常启动**：依次读取 IdeaLab 根规则、项目入口与状态、锁定提交的流程。报告包含每次读取的 ref 及审批状态。
2. **缺少项目级版本**：使用 IdeaLab 接入规范定义的固定默认版本。无法解析固定提交时记录阻塞。
3. **缺少执行授权**：已有灵感记录可以恢复和汇报，M4 保持未授权。
4. **质量回退**：构造 S2 缺陷，确认回到责任人、修订后复验。若影响已批准设计，重新提交审批。
5. **审批与恢复**：跨会话从项目记录恢复，核对成果版本。待审批时停在该门禁，获得批准后按记录范围推进。
6. **能力降级**：分别验证 Skill 未安装、独立上下文不可用、无法按角色切换模型时的报告，记录未达到的门槛。
7. **模型分配**：对低复杂度常规任务和高复杂度高影响任务分别提出分配。确认选择理由符合模型政策，并核实环境实际使用的模型与报告一致。
8. **预算升级**：模拟推荐升级到更高成本模型但预算未覆盖。确认先暂停升级并请求授权，原有工作仍在授权范围内继续。
9. **里程碑规划**：检查计划明确审批点。合并阶段时，确认执行证据与独立审查证据都保留，未批准前不跨越门禁。
10. **角色效用**：检查组队记录中的每个角色都对应独立任务或专业缺口。重复职责应合并，或解释其独立价值。

只有附有运行证据的场景才能标为通过。
