# 接入试运行用例

1. 正常启动：依次读取 IdeaLab 根文件、项目入口与状态、锁定提交的流程。验收记录包含每次读取的 ref 及审批状态。
2. 缺少项目级版本：使用 IdeaLab 接入规范定义的固定默认版本。无法解析固定提交时记录阻塞。
3. 缺少执行授权：已有灵感记录可以恢复和汇报，M4 保持未授权。
4. 质量回退：构造 S2 缺陷，确认回到责任人、修订后复验。若影响已批准设计，重新提交审批。
5. 审批与恢复：跨会话从项目记录恢复，核对成果版本。待审批时停在该门禁，获得批准后按记录范围推进。
6. 能力降级：分别验证 Skill 未安装与独立上下文不可用时的报告，记录为未验证或未达到对应门槛。
