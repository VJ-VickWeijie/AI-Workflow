# Work 与 Codex 启动及交接

向当前环境发起明确请求：「接手 IdeaLab 的 <项目>，先读取 IdeaLab README 和 AGENTS，再读取项目资料，随后按项目锁定提交加载 AI-Workflow，核对审批状态后执行已授权工作。」从 PR 验收接入时，明确给出待审分支，并记录读取的提交。

Work 可通过有权读取两仓的 GitHub 连接器打开文件。Codex 可使用同一连接器或有权限的仓库检出。核对实际读到的提交、项目阶段、批准记录与可用工具。工作流不可读或执行授权缺失时，记录具体缺口，保留可做的只读核查。

交接在项目文档或 PR 保存里程碑报告、当前证据、未解决事项与可接手入口。接收者重新执行读取顺序。Skill 仅在当前环境可实际发现和调用时记录为已加载。并行代理、独立审查、自动唤醒各自按平台能力验证。
